# markdown-render-speed-02 entry

An original, dependency-free Markdown parser (`parse.js`) plus a small driver
(`main.ts`). `parse(markdown)` renders the same HTML as marked 18.1.3 with its
default options (GFM on), and `main.ts` reads `/input/cases.json`, renders each
case on its own, and writes `/output/html.json`.
